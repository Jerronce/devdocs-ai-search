# DevDocs AI Search

A documentation search interface that helps developers search sample docs, filter results, and generate a practical implementation summary.

## Features

- Search documentation snippets
- Filter by topic
- Highlight relevant matches
- Generate developer-friendly summaries
- Browser-only demo

## How to run

Open `index.html` in your browser.

## Tech stack

- HTML
- CSS
- JavaScript

## Portfolio value

This project demonstrates developer tools UX, search interfaces, information architecture, and front-end interaction design.
